# Анимация MoCapGate в Maya

Пользовательский путь: [Русский](../../README.md#экспорт-в-blender-maya-и-движки) · [English](../../README.en.md#export-to-blender-maya-and-engines). Подробно о ригах: [риги Maya](../../docs/maya-rigs.ru.md).

## Сцена Maya (.ma)

1. В «Настройки» → «Персонаж Maya» выберите **Man_Rig**, **«Скелет захвата»** или **«Свой риг Maya»**.
2. Обработайте дубль и нажмите **«Скачать сцену Maya (.ma)»**. При выбранном Man_Rig сцена содержит персонажа
   Man_Rig (геометрия, скиннинг, анимация); иначе — скелет захвата. Ключи стоят на целых кадрах 1…N, FPS сцены = FPS экспорта.
   Blender для `.ma` не нужен.
3. Если Maya найдена, можно нажать **«Открыть персонажа в Maya»** — откроется сцена с выбранным ригом
   (для своего рига — с переносом по профилю).
4. Для поправок скачайте **«Инструменты правок Maya (.py)»**, откройте в **Script Editor → Python** и выполните:
   кнопка Create additive correction layer создаёт слой `MoCapGate_Corrections`. Правки — через суставы, без IK/FK-контроллеров.

## FBX и HumanIK

1. Установите Blender и проверьте его путь в настройках Studio — он используется для конвертации.
2. Нажмите **«Сделать FBX»**. В группе будут экспортированы все участники; выберите ID и скачайте его FBX.
   FBX всегда содержит скелет захвата.
3. Импортируйте FBX в Maya, создайте определения исходного и целевого персонажей HumanIK, сопоставьте обязательные
   суставы, проверьте позы покоя и оси, запеките анимацию на целевой риг.

CLI: `python3 mocapgate.py process "/path/to/take" --fbx` (Windows: `python`).

Имена костей следуют стилю Mixamo, но автоматическая HumanIK-характеризация в MoCapGate не реализована. Число костей зависит от модели и опций: тело, фиксированные окончания, пальцы; у GEM-X — скелет SOMA с глазами и челюстью. Иерархия показана в Studio («Структура скелета»).

## Мимика

При включённой опции «Полное лицо и мимика» 52 кривые ARKit ставятся ключами на атрибуты узла `FaceExpressions` в `.ma`;
FBX получает меш `FaceExpressions` с blend shapes. У Man_Rig нет лицевых blend shapes: соедините атрибуты `FaceExpressions`
со своим узлом blendShape. Сырые точки лица остаются в JSON. [Мимика и кисти](../../docs/facial-expressions.ru.md).

## Границы проверки

Формат `.ma`, ключи, единицы времени и расчёты поворотов проверены автотестами; обратный импорт FBX проверялся в Blender.
**Открытие сцены, перенос и инструменты правок внутри Maya не проверялись**; эти инструкции не являются отчётом о тесте HumanIK.
[Матрица проверок](../../docs/verification.md).
