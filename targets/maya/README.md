# Анимация MoCapGate в Maya

Пользовательский путь: [Русский](../../README.md#экспорт-в-blender-maya-и-движки) · [English](../../README.en.md#export-to-blender-maya-and-engines).

## Получить FBX

1. Установите Blender и проверьте его путь в настройках Studio — он используется для конвертации.
2. Откройте готовый дубль и нажмите **«Сделать FBX»**. В группе будут экспортированы все участники.
3. Выберите конкретный ID, скачайте его FBX и импортируйте в Maya. При необходимости проверьте загрузку FBX-плагина.
4. Если Maya найдена, можно воспользоваться **«Открыть FBX в Maya»**.

CLI: `python3 mocapgate.py process "/path/to/take" --fbx` (Windows: `python`). BVH напрямую доступен без Blender; этот путь в Maya использует FBX.

## Ретаргет через HumanIK

Создайте определение исходного персонажа для импортированного скелета и определение целевого персонажа для своего рига. Сопоставьте обязательные суставы, проверьте позы покоя и направление осей. Выберите источник движения, проверьте результат на целевом персонаже и запеките анимацию.

Имена костей следуют стилю Mixamo, но автоматическая HumanIK-характеризация в MoCapGate не реализована. Число костей зависит от опций и версии дубля: тело, фиксированные окончания, пальцы, а для полного SMPL-X — челюсть и глаза. Иерархия показана в Studio.

FBX содержит скелет и анимацию, без поверхности SMPL-X и лицевых blendshape-каналов. Коэффициенты лица доступны отдельно в JSON и требуют совместимого лицевого рига и собственного переноса каналов.

## Границы проверки

Обратный импорт FBX проверялся в Blender. Исторический Windows-стенд не включал Maya; эти инструкции не являются отчётом о выполненном тесте HumanIK. [Зафиксированные проверки](../../docs/multiple-people-real-test.md).
