# Анимация MoCapGate в Blender

Пользовательский путь: [Русский](../../README.md#экспорт-в-blender-maya-и-движки) · [English](../../README.en.md#export-to-blender-maya-and-engines).

## Импорт BVH

1. В Studio выберите дубль и конкретный ID, если участников несколько.
2. Скачайте BVH.
3. В Blender: **File → Import → Motion Capture (.bvh)**, выберите файл.
4. Установите **Scale = 0.01**: MoCapGate пишет BVH в сантиметрах. Для обычного импорта оставьте оси Forward −Z, Up Y.
5. Проверьте частоту кадров и интервал анимации относительно дубля. Проиграйте начало, середину и конец.

Появляется арматура с движением, а не готовый персонаж. Если Blender найден в «Модели и инструменты», **«Открыть в Blender»** в Studio выполняет подготовленный импорт.

## Перенос на свой риг

Сопоставьте исходный и целевой скелеты средствами своего ретаргет-инструмента или constraints, согласуйте масштаб и позу покоя, затем запеките анимацию на целевой риг. Проверьте плечи, локти, стопы и root motion. Имена `Hips`, `Spine`, `LeftUpLeg`, `LeftArm` и другие следуют стилю Mixamo; префикс `mixamorig:` включается отдельно в дубле и требует повторной обработки. Совпадение имён не гарантирует автоматического ретаргета.

Для GVHMR основное тело — 22 моделируемых сустава; GEM-X даёт скелет SOMA с 77 суставами (тело, пальцы, глаза, челюсть). Экспорт может дополнительно содержать фиксированные окончания цепочек и пальцы. Смотрите настоящую иерархию в **«Структура скелета»** вместо предположения о постоянном количестве костей. Прямой CLI-конвертер GVHMR и старые дубли могут иметь более короткую иерархию.

## FBX и игровые движки

Для FBX из Studio нужен установленный Blender. **«Сделать FBX»** конвертирует скелет и анимацию; при включённой мимике добавляется меш `FaceExpressions` с 52 blend shapes ARKit и их анимацией. Поверхность SMPL-X не включается. Кривые мимики есть также в `<дубль>.face.csv`; сырые точки лица остаются в JSON ([мимика](../../docs/facial-expressions.ru.md)).

Чтобы получить персонажа с мешем, используйте блок **«Свой персонаж»** ([перенос на свой персонаж](../../docs/own-character.ru.md)) или экспорт **«Для игровых движков»** ([движки](../../docs/engines.ru.md)) — оба работают через Blender. Перенос проверен повторным импортом в Blender 3.5/4.2/5.2 на тестовых ригах.

[MeshGate](https://github.com/MaverickGH/meshgate) — необязательный инструмент для подготовки ассетов, а не условие импорта BVH или экспорта из Blender.
