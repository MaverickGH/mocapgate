# Man Rig

`Man_Rig.ma` — пользовательский Maya 2026 риг, предоставленный для MoCapGate.
Пользователь разрешил включение и распространение 2026-10-07, указав, что риг
находится в открытом доступе. Автор и исходный URL пока не установлены.
Это разрешение не является заявлением, что сторонний риг лицензирован MIT.
Сведения исходной сцены сохранены; состав изменений копии указан ниже. MoCapGate импортирует её
без выполнения script nodes. Для отдельного рига укажите локальный `.ma`
в настройках Maya. При экспорте учитываются ориентации суставов и длины костей.

Bundled copy: personal absolute texture paths and Maya-generated UI/playback restoration scripts were removed. Mesh, joints and skinning are preserved. Textures were not supplied. The original user file is unchanged.
