# MoCapGate Studio

Локальное приложение: видео или запись с камеры → анимация скелета → проверка → BVH / FBX для Blender, Maya и движков.

```bash
python3 mocapgate.py studio          # в браузере (работает только на этом компьютере)
```
или установщик для macOS / Windows / Linux (см. [docs/install.md](../../docs/install.md)) — то же самое в своём окне.

## Вкладки

| Вкладка | Что там |
|---|---|
| **Дубли** | библиотека дублей; новый дубль — перетащить видео или результат из Colab; у дубля: видео с оверлеем (найденные точки + наш скелет, спроецированный обратно), полоса качества по кадрам, 3D-просмотр BVH, проверка с советами, перенастройка, экспорт |
| **Камера** | выбор камеры, разрешение, FPS, обратный отсчёт; **живая проверка** — скелет поверх картинки и подсказки «всё тело в кадре / далеко / темно»; запись → сразу дубль |
| **Статус и ИИ** | что найдено (Python, GPU, Blender, Maya, ffmpeg, uv), установка MediaPipe и моделей, GVHMR (Colab или свой GPU), модель SMPL-X |
| **Настройки** | язык (RU/EN), папка дублей, распознавание по умолчанию, сглаживание, фиксация стоп, фокус камеры, пути к Blender / Maya / GVHMR |

## Чем распознаётся движение

| Способ | Где работает | Качество | Лицензия |
|---|---|---|---|
| **MediaPipe** | на этом компьютере, без видеокарты | тело, опциональные кисти и лицо; траектория — по кадру | Apache-2.0 |
| **GVHMR · Colab** | GPU Google при наличии доступа: ноутбук `colab/MoCapGate_GVHMR.ipynb` → архив `*_mocapgate.zip` → в дубль | тело и траектория в мире; качество зависит от видео | некоммерческая |
| **GVHMR · этот ПК** | своя видеокарта NVIDIA, GVHMR установлен по его инструкции; папку и Python указать в «Настройках» | то же | некоммерческая |

Группы экспериментальные. Детали требуют видеоряда и достаточной видимости;
SMPL-X-поверхность требует собственной модели и torch/smplx. Полные инструкции:
[Русский](../../README.md) · [English](../../README.en.md).

## Как устроено

`server.py` — сервер на stdlib Python, только 127.0.0.1, каждый вызов API с токеном сессии, Host только loopback
(как у MeshGate Studio). Обработка дубля — дочерний процесс `mocapgate.py process <дубль> --events`, интерфейс
читает его строки-события и может отменить. Десктоп-оболочка (`desktop/`, Tauri) использует встроенный Python нативного пакета (в разработке — найденный Python), запускает сервер
и открывает его адрес в окне; лог — `~/Library/Logs/dev.mocapgate.studio/studio.log` (macOS),
`%LOCALAPPDATA%\dev.mocapgate.studio\logs\studio.log` (Windows).

Интерфейс — `ui/` без сборки: `studio.js` (логика, RU/EN), `viewer3d.js` (three.js), `studio.css`.
Веб-библиотеки для офлайн-работы кладёт `scripts/vendor_web.py` (сборка делает это сама; без них — CDN).

Нативная desktop-сборка требует заранее проверенный пакет и
`MOCAPGATE_NATIVE_PACKAGE`: [сборка и проверки](../../docs/code-protection.ru.md).
