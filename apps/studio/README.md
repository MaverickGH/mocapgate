# MoCapGate Studio

Локальное приложение: видео или запись с камеры → анимация скелета → проверка → BVH / сцена Maya / FBX / экспорт для движков.

```bash
python3 mocapgate.py studio          # в браузере (работает только на этом компьютере)
```
или установщик для macOS / Windows / Linux (см. [docs/install.md](../../docs/install.md)) — то же самое в своём окне.

Описание соответствует 0.3.3 beta; в стабильной 0.3.2 — предыдущий интерфейс.

## Вкладки

| Вкладка | Что там |
|---|---|
| **Дубли** | библиотека; **«+ Импорт видео»** — видео или результат Colab (опция «Каждое видео — отдельный дубль в очереди»); у дубля: видео с оверлеем, полоса качества, 3D (Man_Rig, тело распознавания, кости), «Проверка движения», «Сравнение распознаваний», «Очередь обработки», участок In–Out, «Исправить эти кадры», экспорт (BVH, `.ma`, FBX, мимика CSV, «Для игровых движков», «Свой персонаж», фрагменты), «Предыдущие версии анимации» |
| **Камера** | выбор камеры, разрешение, FPS, обратный отсчёт; **живая проверка** (MediaPipe Tasks Vision в браузере) — скелет поверх картинки и подсказки; запись → дубль выбранной моделью |
| **Модели и инструменты** | мастер **«Установка шаг за шагом»**: «Проверить компьютер» (с кнопками исправлений, включая память WSL), «Установить всё рекомендуемое», «Открыть демо-дубль», «Отчёт для поддержки»; «Проверить готовность системы»; карточки компонентов (GEM-X, GVHMR, SMPL-X, Blender, Maya, ffmpeg, uv, MediaPipe) с журналом установки |
| **Настройки** | язык, папка дублей, распознавание по умолчанию, проверка новых версий, персонаж Maya (Man_Rig / скелет захвата / свой `.ma`), «Профили персонажей Maya», пути GEM-X (папка, Python, WSL), SMPL-X, Blender, Maya, ручные пути GVHMR (окружение Python/WSL, дистрибутив WSL) |

## Чем распознаётся движение

| Способ | Где работает | Лицензия |
|---|---|---|
| **GEM-X · SOMA** | Apple Silicon (ONNX/CoreML) или NVIDIA через WSL2 / Linux; ставится мастером | код Apache-2.0; веса — условия NVIDIA и SAM 3D Body ([модели и лицензии](../../docs/models-licences.ru.md)) |
| **GVHMR · Colab** | GPU Google: ноутбук `colab/MoCapGate_GVHMR.ipynb` → `*_mocapgate.zip` → в дубль | некоммерческая |
| **GVHMR · этот ПК** | NVIDIA через WSL2 / Linux; ставится мастером, ручные пути — в «Настройках» | некоммерческая |

MediaPipe — внутренний помощник: кисти и лицо для GVHMR, мимика для GEM-X, живая проверка камеры. Старый бэкенд `mediapipe` доступен только из CLI и для чтения прежних дублей. Полные инструкции:
[Русский](../../README.md) · [English](../../README.en.md).

## API

Все вызовы `/api/*` требуют токен сессии; изменяющие запросы — POST с JSON.

| Путь | Назначение |
|---|---|
| `GET /api/status` | компоненты, настройки, версия |
| `POST /api/preflight` | проверка компьютера (`core/preflight.py`) |
| `POST /api/setup` | установка компонента (`recommended`, `gemx`, `gvhmr`, `wsl`, `smplx`, …) — задача с журналом |
| `POST /api/support-report` | ZIP для поддержки в «Загрузки» |
| `POST /api/wslconfig` | память и подкачка WSL в `%UserProfile%\.wslconfig` (резервная копия, перезапуск WSL) |
| `POST /api/advise` | подсказка по тексту ошибки |
| `POST /api/diagnostics` | «Проверить готовность системы»: инструменты и окружения моделей |
| `POST /api/smplx` | загрузка `SMPLX_NEUTRAL.npz` или ZIP с сайта |
| `GET /api/update` | новая версия на GitHub (кэш 6 ч; отключается в настройках) |
| `GET/POST /api/queue` | очередь обработки: состояние, `enqueue`, пауза, запуск, удаление записи |
| `GET/POST /api/characters` | библиотека своих персонажей (`.fbx`, `.glb`, `.gltf`, `.blend`) |
| `GET/POST /api/rig-profiles`, `POST /api/rig-mapping` | профили ригов Maya и автоподбор костей |
| `POST /api/takes/<id>/<действие>` | `process`, `attach`, `fbx`, `open`, `rename`, `delete`, `save`, `clip`, `engine`, `retarget`, `repair`, `compare`, `meta` (проект, теги, заметки), `duplicate` (новый дубль из того же видео) |
| `GET /api/takes/<id>/motion-events` | метки «Проверки движения» |
| `GET /api/jobs/<id>`, `POST /api/jobs/<id>/cancel` | строки-события задачи и отмена |

`engine` принимает `preset` (`unreal`, `unity`, `gltf`, `fbx`, `livelink`), участника, `all` и `root_motion`; `retarget` — имя персонажа; `repair` — диапазон кадров. Эти действия запускают `core/studio_tools.py` отдельным процессом.

## Как устроено

`server.py` — сервер на stdlib Python, только 127.0.0.1, каждый вызов API с токеном сессии, Host только loopback
(как у MeshGate Studio). Обработка дубля — дочерний процесс `mocapgate.py process <дубль> --events`, интерфейс
читает его строки-события и может отменить. Десктоп-оболочка (`desktop/`, Tauri) использует встроенный Python нативного пакета (в разработке — найденный Python), запускает сервер
и открывает его адрес в окне; лог — `~/Library/Logs/dev.mocapgate.studio/studio.log` (macOS),
`%LOCALAPPDATA%\dev.mocapgate.studio\logs\studio.log` (Windows). Журналы установки — `logs/` в папке настроек.

Интерфейс — `ui/` без сборки: `studio.js` (логика, RU/EN), `workbench.js` (проверка движения, сравнение, очередь, профили), `viewer3d.js` (three.js), `studio.css`.
Веб-библиотеки для офлайн-работы кладёт `scripts/vendor_web.py` (сборка делает это сама; без них — CDN).

Нативная desktop-сборка требует заранее проверенный пакет и
`MOCAPGATE_NATIVE_PACKAGE`: [сборка и проверки](../../docs/code-protection.ru.md). Архитектура: [docs/architecture.md](../../docs/architecture.md).
