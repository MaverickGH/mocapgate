## Первый запуск beta.9

Скачайте полный **Quickstart ZIP** со страницы выпуска, распакуйте целиком и запустите `INSTALL.cmd`. Также доступны EXE, MSI и переносной native ZIP. Включён CPython 3.12.13; системный Python для упакованного приложения не нужен.

Откройте «Модели и инструменты» → «Установка шаг за шагом» → «Проверить компьютер». Подготовьте рекомендованные зависимости, импортируйте короткое видео одного человека и проверьте результат. Сборка без подписи; контрольные суммы находятся в `SHA256SUMS.txt` выпуска.

## Что есть в 0.3.3 beta

- Обычные модели тела — **GEM-X · SOMA** (экспериментально) и **GVHMR**. MediaPipe остаётся помощником для деталей, живой проверки и отдельных путей; он убран из обычного выбора моделей тела.
- Очередь обработки, видео/проекция/3D, сглаживание, опоры стоп и IK, правки фрагментов и история версий.
- BVH и сцена Maya напрямую. FBX/GLB, пресеты движков и перенос на своего персонажа — через Blender.
- Мимика: 52 кривые ARKit с отдельными вариантами экспорта.
- В beta.9: выбор половины split-screen и калиброванные многокамерные сессии. Обрезка не объединяет ракурсы; сессии нужны отдельные синхронизированные записи статичных камер и измеренная калибровка.
- Проверка качества учитывает наличие данных: без надёжных интервалов опоры стопы дрейф не измеряется. Балл не является процентом точности по эталону.

## Что проверено

Release notes beta.9 сообщают: распакованный Windows runtime — **495 тестов пройдены, 17 пропущены**; FBX проверен через **Blender 4.5.14**. **CUDA-распознавание GEM-X/GVHMR и WSL именно этой сборки не проверялись.** Не считайте проверку пакета доказательством работы GPU-пути.

Качество захвата зависит от видимости суставов, съёмки и модели. Контакты и перенос на вашего персонажа требуют приёмки и доводки. Colab предполагает загрузку видео в Google; локальная обработка оставляет видео на компьютере.

## Код и лицензии

Это публичный нативный снимок с исходниками интеграций. Восемь выбранных реализаций поставляются загрузчиками и нативными библиотеками. Закрытая ветка разработки и её история не публикуются.

Код **beta.9 — Apache-2.0** (LICENSE в ветке выпуска). Стабильный снимок 0.3.2 в `main` сохраняет **MIT** и свой [LICENSE](LICENSE). У моделей, весов и материалов отдельные условия, включая ограничения GVHMR/SMPL-X.
