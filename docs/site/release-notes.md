**MoCapGate Studio 0.3.1 — мокап из видео в Blender, Maya и движки**

- **macOS · Apple Silicon** — `MoCapGate.Studio_0.3.1_aarch64.dmg`: перетащить в «Программы», первый запуск — правый клик → «Открыть». Или быстрый старт `MoCapGate-0.3.1-macos-arm64-quickstart.zip` (приложение + Python + MediaPipe в один клик).
- **macOS · Intel** — `MoCapGate-0.3.1-macos-x64-quickstart.zip`: распаковать, открыть `INSTALL.command`; или `MoCapGate.Studio_0.3.1_x64.dmg`.
- **Windows 10/11** — `MoCapGate-0.3.1-windows-quickstart.zip`: распаковать, дважды нажать `INSTALL.cmd` (без прав администратора).
- **Linux / любая ОС** — `MoCapGate-0.3.1-portable.zip`: распаковать, `python3 mocapgate.py studio`.

Что нового: несколько людей в кадре, пальцы рук и лицо, кости в стиле Mixamo, быстрый старт для Windows и Mac,
режим «верх тела» для съёмки за столом. Сборки без подписи. Контрольные суммы — `SHA256SUMS.txt`
(совпадают со сборкой CI в [MaverickGH/mocapgate v0.3.1](https://github.com/MaverickGH/mocapgate/releases/tag/v0.3.1)).
GVHMR и модель SMPL-X — только некоммерческое использование.
