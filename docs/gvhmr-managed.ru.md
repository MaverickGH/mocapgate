# GVHMR из приложения · 0.3.3 beta

[English](gvhmr-managed.en.md)

На Windows с NVIDIA откройте **«Модели и инструменты»**. Проще всего — **«Проверить компьютер» →
«Установить всё рекомендуемое»**: мастер сам поставит WSL, GVHMR и (если подходит) GEM-X. По шагам:

1. Если WSL ещё не установлен, мастер (или кнопка исправления в проверке компьютера) запускает установку
   WSL / Ubuntu; подтвердите системный запрос администратора. Дождитесь завершения установки Windows,
   перезагрузитесь и при необходимости один раз откройте Ubuntu для создания пользователя.
2. Прочитайте условия GVHMR и моделей, отметьте согласие и нажмите «Установить» в карточке GVHMR
   (или снова «Установить всё рекомендуемое»). Приложение устанавливает зависимости Ubuntu, Python 3.10,
   закреплённую версию GVHMR и официальные веса. Журнал показывает ход установки.
3. Получите SMPLX_NEUTRAL.npz у авторов SMPL-X и загрузите файл (или ZIP с сайта) кнопкой в карточке
   «Модель тела SMPL-X». Модель проверяется, сохраняется в папке настроек и
   автоматически копируется в каталог GVHMR. Пути вводить не нужно.
4. Дождитесь статуса «Готово», импортируйте видео и выберите «GVHMR · этот ПК».
   Приложение приводит видео к 30 FPS, запускает свой GPU через WSL и импортирует
   результат. Для первого теста используйте короткий ролик, одного человека и
   неподвижную камеру; включите «Камера неподвижна (GVHMR)».

Для NVIDIA начните с видео на 5–10 секунд и одного человека.
На картах до 10 ГБ подготовка кадров автоматически идёт порциями по четыре
кадра, чтобы уменьшить расход видеопамяти. Это не гарантирует, что любой
длинный ролик поместится в память: фактический расход памяти зависит от видео.
Установите актуальный драйвер NVIDIA для Windows; CUDA Toolkit отдельно не нужен.

На Linux используется отдельное локальное окружение; git, ffmpeg, компилятор,
Python 3.10 с venv и Tk (в Ubuntu — python3-venv / python3-tk)
должны быть установлены через пакетный менеджер. На Mac локальный CUDA-GVHMR
не поддерживается — используйте GVHMR · Colab; на Apple Silicon доступен локальный GEM-X.

Старое ручное подключение папки GVHMR/Python сохраняется. Путь SMPL-X из загрузки
теперь имеет приоритет и автоматически синхронизируется с подключённой папкой.
Поверхность и точные кости вычисляются в модельном окружении, поэтому NumPy
не нужно устанавливать внутрь защищённого приложения.

Это beta (0.3.3, предварительный выпуск для Windows; в стабильной 0.3.2 этого пути нет).
Распознавание GVHMR на Windows/WSL подтверждено отчётом пользователя на beta.4/5; на нашем
стенде расчёт на NVIDIA не выполнялся. [Что проверено](verification.md).

Установка драйвера и WSL: [инструкция NVIDIA](https://docs.nvidia.com/cuda/wsl-user-guide/index.html).
Модель тела: [сайт авторов SMPL-X](https://smpl-x.is.tue.mpg.de).
