# Автоматическая настройка MoCapGate

В нативном Studio уже есть Python и uv. Устанавливать их отдельно не нужно.

1. Откройте **«Модели и инструменты» → «Установка шаг за шагом» → «Проверить компьютер»**. Проверка покажет систему, память, диск, видеокарту, WSL и доступ к серверам загрузки и подберёт модели. [Подробнее о мастере](setup-wizard.ru.md).
2. Нажмите **«Установить всё рекомендуемое»**. Ставится только недостающее: FFmpeg и Blender, а по результату проверки — WSL2/Ubuntu (Windows), GEM-X и/или GVHMR. Для GVHMR отметьте согласие с условиями моделей. Если пропал интернет — нажмите кнопку снова, загрузка продолжится.
3. Откройте **«Дубли» → «+ Импорт видео»**, выберите **GEM-X · SOMA**, **GVHMR · Colab** или **GVHMR · этот ПК** и нажмите **«Сделать анимацию»**. BVH и сцена Maya работают без Blender; для FBX и экспорта в движки программа использует найденный или установленный Blender.

Компоненты находятся в `~/.cache/mocapgate/` (на Windows — в домашней папке пользователя; GEM-X и GVHMR — внутри WSL). FFmpeg хранится в `tools`, Blender в `tools/blender`, вспомогательный MediaPipe (кисти и лицо) в `mediapipe`. Путь к Blender сохраняется в настройках, FFmpeg находится программой даже после перезапуска без изменения системного PATH.

## GVHMR на NVIDIA

В «Модели и инструменты» откройте карточку GVHMR (или используйте «Установить всё рекомендуемое»), прочитайте условия моделей, подтвердите их и нажмите **«Установить»**. На Windows используется WSL2 / Ubuntu: если Ubuntu отсутствует, программа откроет системную установку WSL. Подтвердите запрос администратора; при запросе Windows перезагрузите ПК. Откройте Ubuntu один раз, завершите её первый запуск и повторите установку GVHMR в MoCapGate. Не нужно вводить команды или вручную указывать Python и папку репозитория. Приложение автоматически подготавливает зависимости Ubuntu, Python, пакеты и четыре необходимых файла весов.

На Linux локальный GVHMR требует NVIDIA и поддерживаемый драйвер CUDA. Отсутствующие системные зависимости устанавливаются через apt-get и pkexec с системным запросом прав; на других дистрибутивах без этих инструментов понадобится пакетный менеджер ОС. Автоматический базовый набор FFmpeg / Blender поддерживается на Windows x64, macOS ARM64/Intel и Linux x64. На Mac локальный GVHMR не поддерживается — используйте GVHMR · Colab; на Apple Silicon GEM-X ставится локально (около 14 ГБ).

## SMPL-X — один ручной файл

Зарегистрируйтесь на [сайте SMPL-X](https://smpl-x.is.tue.mpg.de), примите условия авторов и скачайте модель. В карточке **«Модель тела SMPL-X»** нажмите **«Загрузить SMPLX_NEUTRAL.npz или .zip с сайта»** и выберите `SMPLX_NEUTRAL.npz` или скачанный архив `models_smplx_v1_1.zip`. Не загружайте модель SMPL или SMPL-H.

MoCapGate проверит формат, сохранит файл в папку пользовательских настроек `body_models/SMPLX_NEUTRAL.npz` и перенесёт копию в необходимую папку GVHMR. Самостоятельно создавать каталоги или исправлять путь не нужно. Если окружение GVHMR ещё не настроено, программа отдельно установит CPU-инструменты SMPL-X для точных костей и поверхности тела; скачивание займёт дополнительное место. Модель не входит в приложение и не скачивается без вашей регистрации.

После установки GVHMR и загрузки SMPL-X карточка должна показать готовность. Тогда в «Дубли» выбирайте **GVHMR · этот ПК**. На видеокартах с объёмом памяти до 10 ГБ предварительная обработка идёт порциями по четыре кадра. Доступная память ограничивает длину и сложность видео.

## Если установка прервалась

Журнал остаётся в настройках. Нажмите установку повторно: готовые компоненты сохраняются, неполные файлы не считаются установленными. Кнопка отмены останавливает текущую установку; после отмены её можно запустить снова. Сеть, драйвер GPU и системная перезагрузка при установке WSL остаются необходимыми условиями.

Windows: установленный дистрибутив выбирается автоматически. В «Предпочтения и дополнительные пути → Ручные пути GVHMR → Окружение → WSL» можно указать точное имя любого установленного дистрибутива. Пустое поле включает автоматический выбор. Автоматическая установка системных пакетов требует дистрибутива с apt-get (например Ubuntu или Debian); остальные требуют самостоятельной подготовки зависимостей. Журнал показывает исходную ошибку WSL.
