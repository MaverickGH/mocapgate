# Проверка публичного репозитория — 4 октября 2026

Проверен локальный репозиторий MoCapGate 0.3.1 перед расширением публичной документации: 144 отслеживаемых файла на начало проверки, код CLI и конвейера, сервер и UI, установка/упаковка, тесты и справочные материалы. Проверка типичных секретов охватила также 262 текстовых объекта доступной локальной истории Git (27 коммитов).

## Что оставлено и почему

- **`tests/fixtures/sports2d/two_people.mp4` (~6,2 МБ):** лицензированный регрессионный ролик; используется проверкой целостности, тестом ID и установкой готового примера. Его удаление сломает воспроизводимые проверки и quickstart.
- **`examples/sports2d/`:** готовая анимация, оверлеи и данные деталей для просмотра без распознавания. Видео повторно в этой папке не хранится: установщик копирует его из одного fixture.
- **Старые `detections.json.gz` и `baseline.json`:** сохраняют известный ошибочный результат. Тест проверяет, что он не проходит критерий двух людей; это полезная регрессия, а не лишний экспорт.
- **Иконки разных размеров и копии UI/splash:** ресурсы платформенных установщиков и интерфейса. Обоснования для удаления по одному размеру не найдено.
- **`scripts/`:** установка зависимостей, подготовка моделей, упаковка или воспроизводимое создание графики. Ссылки setup-скриптов на `configure_surface.py`, `prepare_models.py` и `install_example.py` проверены.
- **`docs/site/`:** материалы существующей публикации на сайте; не runtime приложения, но связаны с отдельным каналом распространения. Обложки и их генератор описаны в `release.md`.
- **`requirements.txt`:** не устанавливает зависимости; поясняет stdlib-ядро и отдельные окружения. В README явно указано, что pip-установка этого файла не требуется.
- **`dist/`, виртуальные окружения, node_modules, Rust target и скачанные веб-библиотеки:** локальные сборки и кэш, уже исключённые из Git.

Проход по сложности не выявил подтверждённых крупных частей, которые можно удалить без изменения возможностей или проверок. Новые runtime-зависимости не добавлялись; работа сосредоточена на документации и правилах состава репозитория.

## Публичные данные и лицензии

В текущих отслеживаемых файлах не найдены типичные GitHub/OpenAI/AWS ключи, маркеры приватных ключей, персональные пути `/Users/...`, `.env` и бинарные файлы лицензированных моделей. В текстовых объектах доступной истории не найдены указанные шаблоны ключей. Colab-ноутбук не содержит сохранённых выводов ячеек.

Это проверка конкретных шаблонов и локальной истории, не гарантия отсутствия любых секретов, не анализ удалённых веток и не полный аудит безопасности приложения.

SMPL-X пользователь получает отдельно. Лицензии компонентов сохранены в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md), лицензия Sports2D — рядом с fixture и примером. Скриншоты сняты только на распространяемом демо, без пользовательских дублей; [происхождение изображений](assets/README.md).

## Проверки

- Автоматические тесты ядра, CLI, сервера, деталей, трекинга и ноутбука: **67 тестов, без ошибок; 1 Windows-only тест отмены процессов пропущен на macOS**.
- Studio запущен с отдельными `MOCAPGATE_HOME` и библиотекой в игнорируемом `dist/docs-preview`; просмотр примера и RU/EN проверены, сняты четыре скриншота.
- Публичный релиз 0.3.1 и имена его семи assets проверены через GitHub API. Linux DEB/AppImage и отдельные EXE/MSI не обещаются как опубликованные assets этого релиза.
- Локальные ссылки, якоря двух README, изображения и отсутствие пробельных ошибок проверены. Обе версии отрендерены через GitHub Markdown API; схемы проверены рендерером Mermaid, картинки загружаются.
- Переносной ZIP проверен после распаковки: английский README, картинки, демо-BVH, установка примера и ресурсы локального сервера.

Новые установщики и повторное реальное распознавание GVHMR/MediaPipe в этом проходе не выполнялись. Ранее зафиксированные проверки настоящего видео: [отчёт](multiple-people-real-test.md).
