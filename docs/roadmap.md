# Роадмап MoCapGate

Текущее состояние: стабильная **0.3.2**, подготавливается предварительная **0.3.3-beta.9** (Windows). Этот документ отделяет реализованные возможности от направлений развития; сроки будущих функций не заданы. Пункты, отмеченные «0.3.3 beta», в стабильной 0.3.2 отсутствуют. Что из этого проверено на каких платформах: [матрица проверок](verification.md).

## Уже работает

- [x] CLI, демо-BVH и ядро на стандартной библиотеке Python.
- [x] GEM-X · SOMA: локально на Apple Silicon (ONNX/CoreML) и на NVIDIA через WSL2/Linux; несколько людей (YOLOX+ByteTrack), общая сцена. *0.3.3 beta, экспериментально.*
- [x] GVHMR: импорт `.pt` / `.npz` / JSON, локальный NVIDIA и Colab-ноутбук.
- [x] MediaPipe как помощник: кисти, лицо и живая проверка камеры (прежний бэкенд тела — только CLI).
- [x] Studio: Tauri и браузер, RU/EN, библиотека дублей, видео с оверлеем и 3D.
- [x] Камера: живая проверка, запись, обратный отсчёт и создание дубля.
- [x] Мастер установки: проверка компьютера, «Установить всё рекомендуемое», отчёт для поддержки, `mocapgate.py preflight`. *0.3.3 beta.*
- [x] Сглаживание тела и пальцев, фиксация стоп (GEM-X — контакты и IK ног; GVHMR — коррекция корня), движение на месте.
- [x] Отчёты качества, советы, метки «Проверка движения».
- [x] Несколько людей: отдельные ID, общий таймлайн и экспорт; экспериментальный режим.
- [x] Пальцы рук и мимика: 52 кривые ARKit в CSV, Maya, FBX/GLB и Live Link Face CSV. *0.3.3 beta.*
- [x] Нейтральная поверхность SMPL-X в просмотре с собственной лицензированной моделью.
- [x] BVH, сцена Maya `.ma` с Man_Rig, FBX через Blender, имена Mixamo и опциональный `mixamorig:`.
- [x] Экспорт для движков: Unreal · FBX, Unity · FBX, glTF · GLB, Live Link Face CSV; перенос на свой персонаж. *0.3.3 beta; импорт в движки не проверен.*
- [x] Обрезка дубля: экспорт участка In–Out, бесшовный цикл, корневая кость; исправление кадров и версии анимации. *0.3.3 beta.*
- [x] Пакетная обработка: очередь, автозапуск при добавлении, пауза и возобновление после перезапуска. *0.3.3 beta.*
- [x] Сравнение распознаваний разными моделями на одном видео. *0.3.3 beta.*
- [x] Проверка новых версий (уведомление и ссылка; автообновления нет). *0.3.3 beta.*
- [x] Quickstart Windows/macOS, переносной ZIP, пример Sports2D и регрессионные проверки.

Возможности не означают одинаковую точность на всех видео: [ограничения и реальные проверки](multiple-people-real-test.md).
