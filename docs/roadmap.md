# Роадмап MoCapGate

Текущее состояние: **0.3.1**. Этот документ отделяет реализованные возможности от направлений развития; сроки будущих функций не заданы.

## Уже работает

- [x] CLI, демо-BVH и ядро на стандартной библиотеке Python.
- [x] MediaPipe: локальное распознавание, ретаргет тела, оценка фокуса и траектории.
- [x] GVHMR: импорт `.pt` / `.npz` / JSON, локальный NVIDIA и Colab-ноутбук.
- [x] Studio: Tauri и браузер, RU/EN, библиотека дублей, видео с оверлеем и 3D.
- [x] Камера: живая проверка, запись, обратный отсчёт и создание дубля.
- [x] Сглаживание, фиксация стоп коррекцией корня, пол и движение на месте.
- [x] Отчёты качества и советы; автоматический режим верхней части тела.
- [x] Несколько людей: отдельные ID, общий таймлайн и экспорт; экспериментальный режим.
- [x] Опциональные пальцы рук и лицо, данные деталей в JSON.
- [x] Нейтральная поверхность SMPL-X в просмотре с собственной лицензированной моделью.
- [x] BVH и FBX через Blender, имена Mixamo и опциональный `mixamorig:`.
- [x] Quickstart Windows/macOS, переносной ZIP, пример Sports2D и регрессионные проверки.

Возможности не означают одинаковую точность на всех видео: [ограничения и реальные проверки](multiple-people-real-test.md).

## Качество и устойчивость

- [ ] Полноценный IK ног вместо одной коррекции корня.
- [ ] Улучшение пропорций и скрутки конечностей для MediaPipe.
- [ ] Более устойчивые ID при длительном перекрытии и повторном входе.
- [ ] Повышение покрытия и проверка точности пальцев и мимики.
- [ ] Сравнение альтернативных бэкендов на воспроизводимых видео.
