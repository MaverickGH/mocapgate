# Установка MoCapGate Studio

[English version](install.en.md) · [Решение проблем](troubleshooting.ru.md)

Скачайте пакет со страницы [MoCapGate releases](https://github.com/MaverickGH/app-releases/releases).
Git, Python, Node, Rust и аккаунт GitHub не нужны: в пакете есть свой Python 3.12.13 и uv.

## Что нужно

| | Минимум | Для моделей NVIDIA (GEM-X / GVHMR на этом ПК) |
|---|---|---|
| Система | Windows 10 21H2 (сборка 19044) или Windows 11, x64 | то же + WSL2 с Ubuntu (ставится из приложения) |
| Mac | macOS на Apple Silicon (есть сборка и для Intel) | GEM-X — локально на Apple Silicon (ONNX/CoreML, ~14 ГБ, нужны Command Line Tools); GVHMR — только Colab |
| Память | 8 ГБ ОЗУ | 16 ГБ рекомендовано |
| Видеокарта | не нужна (GVHMR · Colab на любой ОС; GEM-X на Apple Silicon) | NVIDIA RTX с 8 ГБ видеопамяти и драйвером 535 или новее; GVHMR не работает на RTX 50 |
| Диск | 5 ГБ для приложения и базовых инструментов | около 50 ГБ свободно для всех моделей (GEM-X ~30 ГБ, GVHMR ~15 ГБ) |
| Интернет | при первой установке (около 1–2 ГБ) | десятки ГБ при установке моделей |

**Нет NVIDIA?** Используйте **GVHMR · Colab** (бесплатный GPU Google в браузере, любая ОС), а на Mac с Apple Silicon — ещё и локальный GEM-X. MediaPipe ставится как помощник для кистей, лица и живой проверки камеры; моделью тела он больше не является.

## Быстрая установка (Windows)

1. Скачайте `MoCapGate-<версия>-windows-x64-quickstart.zip`.
2. **Распакуйте весь архив**: правой кнопкой по ZIP → «Извлечь все…» → обычная папка
   (например, «Загрузки» или `C:\MoCapGate`). Не запускайте файлы двойным щелчком прямо внутри ZIP —
   тогда Windows видит только один файл, и установка остановится с подсказкой.
   Не распаковывайте в OneDrive и в очень длинные пути.
3. (Необязательно) Запустите **CHECK-COMPUTER.cmd** — проверка компьютера, ничего не устанавливает.
4. Запустите **INSTALL.cmd**. Права администратора не нужны.
   - Если появится синее окно **«Windows защитила ваш компьютер»** (SmartScreen): сборки MoCapGate
     не подписаны платным сертификатом, поэтому Windows не знает издателя. Это не проверка на вирусы.
     Нажмите **«Подробнее» → «Выполнить в любом случае»**, только если архив скачан со страницы релизов выше.
5. INSTALL.cmd делает следующее (окно остаётся открытым до конца и показывает итог):
   - проверяет, что архив распакован полностью, Windows 64-битная, свободно не меньше 5 ГБ и Studio закрыт;
   - ставит приложение для текущего пользователя в `%LOCALAPPDATA%\MoCapGate Studio`;
   - скачивает FFmpeg, Blender и помощник MediaPipe (кисти и лицо), добавляет демо-дубль;
   - выполняет проверку компьютера и запускает MoCapGate Studio.

   Журнал установки: `%LOCALAPPDATA%\MoCapGate Studio\logs\install-<дата>.log`.
   Если установка прервалась — запустите INSTALL.cmd ещё раз: готовое сохраняется, загрузки продолжаются.

Альтернатива без quickstart: установщик `.exe` из релиза (меню «Пуск» → MoCapGate Studio), затем шаги ниже.

## Первый запуск

1. Откройте вкладку **«Модели и инструменты»** — вверху блок **«Установка шаг за шагом»**.
2. Нажмите **«Проверить компьютер»**. Проверка показывает систему, память, диск, видеокарту и драйвер,
   WSL, интернет и подсказывает, какие модели подходят этому ПК. Красные пункты блокируют только
   соответствующую модель; у каждого есть кнопка или команда исправления.
3. Отметьте согласие с условиями GVHMR и моделей (некоммерческое использование) и нажмите
   **«Установить всё рекомендуемое»** — приложение поставит то, что подходит по проверке (базовые
   инструменты, а на ПК с NVIDIA — GEM-X и/или GVHMR). Уже установленное пропускается.
   Отдельные модели можно ставить кнопкой **«Установить»** в их карточках.
4. **«Открыть демо-дубль»** — см. [проверку на демо-дубле](#проверка-на-демо-дубле).

### Windows + NVIDIA: WSL2 и Ubuntu

GEM-X и GVHMR работают в Linux-окружении WSL2. Если его нет, приложение запустит системную установку:

1. Подтвердите запрос **администратора** Windows (UAC). Это единственный шаг с правами администратора.
2. **Перезагрузите** компьютер, если Windows попросит.
3. После перезагрузки откроется окно **Ubuntu**. Придумайте имя пользователя и пароль Linux
   (латиницей; это отдельная учётная запись внутри Ubuntu, не пароль Windows). Дождитесь приглашения
   `имя@компьютер:~$` и закройте окно.
4. Вернитесь в MoCapGate и снова нажмите **«Установить всё рекомендуемое»** — установка продолжится.

Если Windows сообщает, что виртуализация выключена (`0x80370102`), включите **Intel VT-x / AMD SVM**
в BIOS/UEFI. Проверить: Диспетчер задач → Производительность → ЦП → «Виртуализация: Включено».
Подробнее — [WSL в решении проблем](troubleshooting.ru.md#wsl).

### SMPL-X (по желанию, для GVHMR и точной фигуры)

Модель SMPL-X нельзя распространять вместе с программой — её скачивает каждый пользователь сам:

1. Зарегистрируйтесь на [smpl-x.is.tue.mpg.de](https://smpl-x.is.tue.mpg.de/download.php) и примите
   [лицензию SMPL-X](https://smpl-x.is.tue.mpg.de/modellicense.html).
2. Скачайте архив модели SMPL-X.
3. В «Модели и инструменты» → карточка **«Модель SMPL-X»** выберите `SMPLX_NEUTRAL.npz` (или скачанный ZIP).
   Приложение само проверит файл и разложит его по нужным папкам.

### Blender (для FBX, Unreal/Unity, своего персонажа)

Ставится автоматически в составе рекомендуемого набора. Уже установленный Blender приложение находит само;
путь можно указать в «Настройках». BVH и сцена Maya работают без Blender.

### Проверка на демо-дубле

Откройте **Demo — Sports2D, two people** в списке дублей и нажмите Play: должны двигаться два скелета.
Демо работает без GPU и без SMPL-X. Если установлены GEM-X или GVHMR, нажмите **«Сделать анимацию»**, чтобы
проверить обработку на этом компьютере; без NVIDIA и Apple Silicon проверьте путь через **GVHMR · Colab**.
Демо проверяет воспроизведение и установку, а не точность мокапа.

## macOS

1. Скачайте `MoCapGate-<версия>-macos-arm64-quickstart.zip` (Apple Silicon) или `-x64` (Intel)
   и распакуйте его двойным щелчком.
2. Сборка не подписана Apple. При первом открытии **INSTALL.command**: щелчок правой кнопкой
   (Control-щелчок) → «Открыть» → «Открыть». Если macOS всё равно блокирует: «Системные настройки» →
   «Конфиденциальность и безопасность» → «Всё равно открыть». Скрипты защиту macOS не отключают.
3. INSTALL.command копирует приложение в `~/Applications`, ставит FFmpeg, Blender, помощник MediaPipe и демо-дубль.
   Пароль администратора не нужен. Журнал: `~/Library/Logs/MoCapGate/`.
4. Дальше — как в [первом запуске](#первый-запуск). На Apple Silicon GEM-X ставится локально (около 14 ГБ;
   если попросит — `xcode-select --install` для Command Line Tools). GVHMR на Mac — через GVHMR · Colab.

Каждая сборка для Mac проверяется отдельно: успешный тест на Windows не подтверждает работу на Mac.

## Если что-то не так

- [Решение проблем](troubleshooting.ru.md): SmartScreen, антивирус, прокси, WSL, драйвер, память, диск.
- Кнопка **«Отчёт для поддержки»** в «Модели и инструменты» сохраняет в «Загрузки» файл с результатами
  проверки, версиями и журналами установки (без видео и анимаций). Вы сами решаете, кому его отправить.
- Повторная установка безопасна: готовые компоненты и докачанные файлы сохраняются.

## Для сопровождающих: сборка

Сборка выполняется только в закрытом исходном проекте на CPython 3.12.13 с `requirements-native.txt`
и `scripts/native_packaging.py`; распакованный пакет проверяется до упаковки desktop-оболочки:

```bash
python scripts/native_packaging.py build --out dist/native-package
python tests/test_native_package.py dist/native-package --require-blender
export MOCAPGATE_NATIVE_PACKAGE="$PWD/dist/native-package"
cd apps/studio/desktop && npm ci && npx tauri build
```

Quickstart ZIP: `scripts/make_windows_quickstart.py --portable <native.zip> --installer <setup.exe>` и
`scripts/make_macos_quickstart.py --portable <portable.zip> --dmg <app.dmg> --arch arm64`.
Подробности: [проверка native-пакета](native-verification.md), [распространение](distribution.md).
