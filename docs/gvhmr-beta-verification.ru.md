# Проверка GVHMR beta · 0.3.3-beta.1

Собранный код: `c6c89c29f4a68bb7d5f4337bb731f01b1501dfd2` приватного исходного репозитория.
Основной runtime Studio — встроенный CPython 3.12.13; GVHMR — отдельный Linux Python 3.10 через WSL2.
Версия приложения — 0.3.3-beta.1, числовая версия MSI — 0.3.3.1.

- [Windows build](https://github.com/MaverickGH/app-releases/actions/runs/37294190648): восемь выбранных модулей скомпилированы; распакованный пакет проверен своим Python, включая обработку данных, ошибки, отмену и настоящий FBX через Blender. Собраны EXE и MSI.
- [Проверка установщиков](https://github.com/MaverickGH/app-releases/actions/runs/37295226831): EXE установлен на Windows, его ресурсы повторно распакованы и проверены. Выполнено 76 тестов, два зависящих от платформы/окружения пропущены; остальные прошли. FBX экспортирован. MSI извлечён штатным msiexec, ресурсы и хеши восьми библиотек проверены.
- [Linux model environment](https://github.com/MaverickGH/app-releases/actions/runs/37293455127): зависимости установленного upstream GVHMR, полный импорт demo и PyTorch3D extension прошли. Обработчик rest-позы проверен с настоящим NumPy в Python 3.10 из посторонней рабочей папки, на собственных синтетических массивах.
- На этом Mac ARM64: нативная распакованная копия, 76 тестов (один Windows-тест пропущен), настоящий Blender FBX и интерфейс RU/EN прошли; ошибок JavaScript не найдено. Это не проверка Windows CUDA.
- Официальная папка Google Drive проверена на наличие всех четырёх требуемых checkpoint-файлов. Полное скачивание многогигабайтных весов и CUDA-инференс на NVIDIA здесь не выполнялись.

Собственные изменения проверяют приоритет загруженной модели, синхронизацию пути,
аргументы WSL с пробелами, отсутствие ложного статуса CUDA, согласие с условиями,
запрет параллельных установок, порядок кадров при обработке порциями и остановку
Linux-процесса после прекращения heartbeat.

Настоящий расчёт на NVIDIA остаётся обязательной пользовательской проверкой.
Для неё выпускается Windows prerelease; стабильный релиз 0.3.2 не заменяется.
Лицензированные SMPL-X модели не включены. Модель пользователь получает у авторов.
