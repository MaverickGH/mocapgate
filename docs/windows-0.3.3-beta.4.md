# MoCapGate Studio 0.3.3-beta.4 — Windows x64

> **Исторический документ.** Отражает состояние на дату отчёта; текущий статус — в [README](../README.md) и [матрице проверок](verification.md).

Обновление на основе актуального закрытого сборочного проекта. Включены
просмотр и сравнение движения, последовательная очередь, профили рига,
проверки готовности и исправления автоматической установки из beta.3.

## Установка

Запустить `MoCapGate-0.3.3-beta.4-windows-x64-setup.exe`, затем открыть
MoCapGate Studio из меню «Пуск». Python 3.12.13, uv и веб-библиотеки включены.
Для переносного запуска распаковать `*-windows-x64-native.zip` и открыть
`START_WINDOWS.cmd`. Папку нужно сохранить целиком.

MediaPipe, Blender и FFmpeg устанавливаются из настроек приложения;
первая загрузка требует интернета. BVH не требует Blender. GVHMR и SMPL-X
настраиваются отдельно и сохраняют собственные некоммерческие условия.
Настоящий CUDA-запуск GVHMR и установка с нуля на другом ПК этой проверкой
не подтверждаются. Windows-сборка не подтверждает работу Mac/Linux.

## MetaHuman — экспериментальные утилиты

В пакет включены Epic OpenRigLogic для Windows x64 и встроенного Python,
проверка DNA, экспорт 28 GUI-каналов и скрипт импорта в Maya. Персонажи Fab,
Faceboard, SMPL-X и пользовательские записи не включены.

Из папки `mocapgate` установленного приложения:

```powershell
./python/python.exe -B tools/metahuman_inspect.py C:/path/head.dna --runtime tools/metahuman/runtime --require-geometry
./python/python.exe -B tools/metahuman_face.py C:/path/person_1.capture_file.json --faceboard C:/path/faceboard.json --output C:/path/person_1.metahuman.json
```

Полноценное лицо MetaHuman в Studio ещё не подключено; нужны DCC Export из
Unreal и калибровка на настоящем персонаже. Импорт внутри Maya пока не
проверен. Доступный просмотр Man Rig и экспорт Maya-сцены относятся к
телу, а не к полноценному лицевому ригу MetaHuman.

Риг сохраняет одинаковые переносы строк при Windows checkout. Сравнение
подготовленных трансформаций допускает погрешность 1e-12 из-за различий
математических библиотек; топология, индексы и сведения о риге проверяются точно.

Установщики не подписаны. Перед запуском можно сверить `SHA256SUMS.txt`.
Стабильные пакеты 0.3.2 и существующие Mac/Linux beta.3 остаются доступными.
