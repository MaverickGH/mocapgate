# MoCapGate Studio 0.3.3-beta.5 — подготовка релиза

> **Исторический документ.** Отражает состояние на дату отчёта; текущий статус — в [README](../README.md) и [матрице проверок](verification.md).

Исправляется воспроизводимость установки GEM-X в Windows/WSL2:
CUDA 12-совместимый ONNX Runtime 1.20.2, проверяемая возобновляемая загрузка
пакета, пути NVIDIA-библиотек до запуска worker, реальный GPU smoke-test
и запас времени для холодного старта WSL. Новая установка проверяет 30 ГБ
свободного места вместо прежних 14 ГБ.

Быстрые установщики используют встроенный CPython 3.12.13 и uv для native-пакетов.
Для Mac-скриптов закреплены LF-переносы строк. Quickstart принимает ZIP
как с общей корневой папкой, так и без неё. Инструкция моделей и распространения
обновлена для готовых установщиков и закрытого сборочного проекта.

Включён воспроизводимый Sports2D-пример: 230 кадров, 30 FPS, два подготовленных
MediaPipe-трека и исходное видео. Модели SMPL-X/Fab, токены и пользовательские
записи не включены. SAM-Body4D worker умеет явно проверять checkpoints до
создания пустого результата; эксперимент пока не заявлен готовым бэкендом.

Включены неизменённые модели MediaPipe Heavy, кистей и лица: около 40 МиБ,
Apache-2.0, лицензии и SHA-256 рядом с файлами. Их первая установка из пакета
не требует загрузки весов; зависимости MediaPipe, детектор людей и инструменты
экспорта пока требуют интернета при первой установке.

Windows: проверены полный GEM-X клип (230 кадров, 77 суставов), BVH/Maya/FBX;
GVHMR и MediaPipe — два человека, 230 кадров и FBX. В отдельном пустом кэше
установлены MediaPipe, Blender 4.5.9, FFmpeg и FFprobe, затем повторно обработан
пример и экспортированы оба человека. Это проверки на данном ПК, не гарантия
точности любой записи. Финальный установщик проверяется отдельно от исходников.
GEM-X: один SOMA-трек, статичная камера; многопользовательский захват не реализован.
Полная лицевая анимация MetaHuman в Studio/Maya/Unreal ещё не подтверждена.
Этот Windows-релиз не подтверждает работу новой версии на macOS/Linux.
