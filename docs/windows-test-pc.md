# Проверка Windows — 3 октября 2026

**Исторический отчёт о первоначальном прогоне.** Ниже сохранены условия и результаты
того этапа. Позже групповой детектор исправлен, а полный GVHMR с пользовательской
SMPL-X прошёл проверку: актуальный результат — в [отчёте настоящего видео](multiple-people-real-test.md).
Этот документ не описывает текущий статус всех возможностей 0.3.1.

Ветка: `codex/test-pc`. Слияние в `main` выполняется отдельно после проверки.

**Уточнение после проверки настоящего ролика:** групповой MediaPipe пока не готов:
два человека разделились на девять ID. Ранее использовались фотография и её
зеркальная копия, что подтверждало только разделение фигур и экспорт.
Подробности: [проверка настоящего видео](multiple-people-real-test.md).

Стенд: Windows 11 Pro x64 (22621), Python 3.12.15 от uv, WebView2,
Blender 4.5.14 LTS, Depstech webcam, NVIDIA GTX 1080 (8 ГБ).
Сборка: Rust stable, Visual Studio 2022 C++ и Windows SDK 10.0.22000.

## Исправления

- Удалённые с Mac файлы `._*` больше не ломают чтение Tauri capabilities;
  метаданные игнорируются Git и не включаются в переносной ZIP.
- Windows-оболочка находит пользовательские Python и Python от uv без PATH.
- uv и ffmpeg из `%USERPROFILE%\.local\bin` доступны при запуске из «Пуска».
- CLI и Python-работники передают Unicode в UTF-8 при старой кодировке консоли.
- Потоки вывода завершённых задач закрываются.
- Уточнены требования к Windows-сборке и переносу проекта с Mac.

## Ограничения

Полное предсказание GVHMR не проверено: отсутствует лицензируемый файл
`SMPLX_NEUTRAL.npz`. Код GVHMR установлен в `D:\AI\GVHMR`, отдельное окружение
Python 3.10 находится в `.venv`. PyTorch 2.3.0+cu121 видит GTX 1080 и выполняет
матричные вычисления на GPU. Веса GVHMR, HMR2, ViTPose и YOLO скачаны с зеркала,
указанного в демонстрации из README GVHMR (официальная папка Google Drive ограничила скачивание).
PyTorch3D 0.7.6 собран с CPU-расширением: без GPU-рендера, для обработки без рендера.
Синтетические тесты проверяют ID при смене порядка, коротком пропуске и пересечении
различимых поз; сложные перекрытия в настоящем групповом видео не проверялись.
Maya не установлена; проверен экспорт FBX
и его импорт в Blender, но не HumanIK в Maya. macOS-сборка на этом ПК не выполнялась.
