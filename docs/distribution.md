# Передача готовых установочных файлов

Исходники открыты в [MaverickGH/mocapgate](https://github.com/MaverickGH/mocapgate).
Готовые пакеты: [app-releases — MoCapGate 0.3.1](https://github.com/MaverickGH/app-releases/releases/tag/mocapgate-v0.3.1).
Получателю достаточно ZIP: аккаунт GitHub, Git, Node и Rust для использования не нужны.

## Windows 10/11 x64

Распакуйте **windows-quickstart.zip** в обычную папку и запустите **INSTALL.cmd**.
Он устанавливает приложение текущему пользователю, Python 3.12, FFmpeg,
MediaPipe heavy, модели кистей/лица и тестовый дубль **Demo — Sports2D, two people**.
После завершения приложение открывается. Для воспроизведения примера выберите
его в «Дублях», оставьте «Все участники» и нажмите ▶.

## macOS: Apple Silicon или Intel

Выберите **macos-arm64-quickstart.zip** для M1/M2/M3/M4 и последующих Apple Silicon;
**macos-x64-quickstart.zip** — для Intel. Распакуйте и запустите **INSTALL.command**.
Приложение копируется в `~/Applications`, зависимости устанавливаются отдельно
в домашней папке, пример добавляется в библиотеку дублей.

Сборки пока не подписаны и не нотарифицированы. macOS может потребовать ручного
разрешения открытия в «Системные настройки → Конфиденциальность и безопасность».
Windows также может показать SmartScreen. Скрипты не отключают защиту системы.
Тесты на macOS-раннерах проверяют установку зависимостей, сборку и сервер;
камера и интерфейс на физическом Mac требуют отдельной проверки.

## Что требуется дополнительно

Для первого установочного запуска нужен интернет: Python, библиотеки и модели
скачиваются автоматически. После установки просмотр подготовленных дублей и
MediaPipe работают локально. Это ещё не полностью автономный offline-установщик.

BVH и данные лица JSON доступны без Blender. Для экспорта FBX установите Blender
3.5+ с https://www.blender.org/download/ и при необходимости укажите путь в
«Настройках». Локальный GVHMR требует отдельного окружения NVIDIA; на Mac
используйте MediaPipe или GVHMR в Colab. Ноутбук включён в пакет:
`colab/MoCapGate_GVHMR.ipynb`; загрузите его через «Файл → Загрузить блокнот»
в Colab. Доступ к GitHub для загрузки ноутбука в Colab не нужен.

Полный аватар SMPL-X — дополнительная опция. Получатель сам регистрируется на
https://smpl-x.is.tue.mpg.de и получает `SMPLX_NEUTRAL.npz`. Модель не входит в
раздаваемые файлы. Затем из папки распакованного пакета:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup_windows.ps1 -FullAvatar -SmplxModel "C:\Models\SMPLX_NEUTRAL.npz"
```

```bash
bash scripts/setup_macos.sh --smplx-model "$HOME/Models/SMPLX_NEUTRAL.npz"
```

Пример показывает двух людей, пальцы и лицо при доступных наблюдениях. Его
оценки качества невысокие: дальние кисти/лица пропускаются. Это проверка
воспроизведения и идентификаторов, а не образец точного захвата движения.

## Следующий формат пакетов

Инструкции выше относятся к опубликованной 0.3.1. Новые нативные пакеты включают
свой CPython, собираются отдельно для каждой ОС/архитектуры и запускаются через
START.sh / START_WINDOWS.cmd. Проверена только локальная macOS ARM64.
