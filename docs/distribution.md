# Передача установочных файлов

Получателю передают EXE/MSI или соответствующий DMG, переносной native ZIP,
при необходимости quickstart ZIP и SHA256SUMS.txt. Исходники закрытого
сборочного проекта не требуются. Пакеты публикуются в
[MoCapGate releases](https://github.com/MaverickGH/app-releases/releases).

Приложение включает CPython 3.12.13, uv, офлайн-ресурсы интерфейса и тестовый
Sports2D-результат для двух людей. Quickstart устанавливает инструменты и
дополнительные модели из официальных источников, затем добавляет пример
в библиотеку. Просмотр подготовленного примера доступен без NVIDIA/SMPL-X.

Включены три модели Google MediaPipe (Heavy, кисти, лицо), около 40 МиБ,
с Apache-2.0 лицензией, указанием авторства и SHA-256. Они устанавливаются
из пакета без повторной загрузки. Остальные зависимости и инструменты
получаются при первой установке через интернет.

Код и веса, разрешённые для распространения, требуют сохранения собственных
лицензий. SMPL-X и персонажи MetaHuman в Git/установщик не включаются;
каждый получатель получает их отдельно. Название «тестовая модель» не меняет
условия. [Как получить и подключить модели](install.md#smpl-x-по-желанию-для-gvhmr-и-точной-фигуры), [модели и лицензии](models-licences.ru.md).

Windows, macOS ARM64 и macOS Intel собираются и проверяются отдельно.
Проверка пакета на компьютере разработчика не равна проверке чистой установки
на всех компьютерах. Требования NVIDIA/WSL2, доступ к моделям и ограничения
экспериментальных интеграций указываются в примечаниях конкретного релиза.
Непроверенную платформу не объявляют готовой.

Исходные модули, compiler work directories, debug symbols, токены, пользовательские
записи и лицензированные модели в раздачу не попадают. Проверка контрольных сумм
не заменяет цифровую подпись; состояние подписи указано в примечаниях релиза.
