# Мастер установки

[English](setup-wizard.en.md) · [Установка](install.md) · [Решение проблем](troubleshooting.ru.md)

С 0.3.3 beta (предварительный выпуск для Windows); в стабильной 0.3.2 мастера нет.
Вкладка **«Модели и инструменты»** → блок **«Установка шаг за шагом»**.

## 1. Проверить компьютер

Ничего не устанавливает. Проверки идут параллельно (до ~20 с):

- система: 64-битная ОС, версия Windows (сборка) или macOS, Apple Silicon / Intel;
- оперативная память (минимум 8 ГБ для GEM-X и GVHMR, лучше 16+);
- место на диске для дублей и для моделей (основа 5 ГБ; GEM-X ~14 ГБ на Mac, ~30 ГБ на Windows/WSL; GVHMR ~15 ГБ);
- папка дублей: доступна ли запись, не синхронизируется ли облаком, длина пути, длинные пути Windows;
- не-ASCII символы в профиле пользователя, прокси;
- видеокарта NVIDIA, драйвер, видеопамять (GEM-X — 8 ГБ, GVHMR — 6 ГБ), поддержка архитектуры GVHMR;
- WSL (Windows): установлен ли, отвечает ли, версия 2, выделенная память;
- Command Line Tools (Mac), найденные инструменты;
- доступ к серверам загрузки, перехват HTTPS, ограничения запросов.

У каждой проблемы — пояснение и **кнопка или команда исправления**. Красный пункт блокирует только
соответствующую модель. Внизу — рекомендация: Apple Silicon → GEM-X локально и GVHMR в Colab;
NVIDIA → GEM-X и/или GVHMR локально; без NVIDIA → GVHMR · Colab.

**Память WSL.** Если WSL выделено слишком мало памяти, кнопка исправления предлагает записать
`memory` и `swap` в `%UserProfile%\.wslconfig`. Запись — только после вашего подтверждения; прежний файл
сохраняется как `.wslconfig.mocapgate-backup`, остальные строки не меняются, затем WSL перезапускается
(`wsl --shutdown`). Пока идёт обработка или установка, кнопка не сработает.

## 2. Установить всё рекомендуемое

Ставит **только недостающее** в нужном порядке: FFmpeg и Blender → WSL2 и Ubuntu (Windows, если нужно) →
GEM-X → GVHMR (по рекомендации проверки). Для GVHMR отметьте согласие с условиями GVHMR и моделей
(некоммерческое использование). Если пропал интернет — нажмите кнопку снова: загрузки продолжаются,
неполные файлы не считаются установленными. После установки WSL Windows может попросить перезагрузку:
перезагрузитесь и снова нажмите «Установить всё рекомендуемое» — установка продолжится.

Модель SMPL-X (для GVHMR) загружается отдельно в карточке «Модель тела SMPL-X»:
`SMPLX_NEUTRAL.npz` или архив с сайта.

## 3. Попробовать

**«Открыть демо-дубль»** открывает пример Sports2D. Демо проверяет воспроизведение, а не точность.

## Проверить готовность системы

Отдельная кнопка «Проверить готовность системы» смотрит уже установленное: найденные инструменты и
окружения, для GVHMR/GEM-X — импорт PyTorch и доступность CUDA. «Проверить компьютер» — до установки,
«Проверить готовность системы» — после.

## Без окна приложения

```bash
python3 mocapgate.py preflight            # то же, что «Проверить компьютер»
python3 mocapgate.py preflight --json --no-network --lang en
python3 mocapgate.py setup recommended    # FFmpeg, ffprobe, Blender
```

Код выхода `preflight`: 0 — блокирующих проблем нет, 2 — есть.

В quickstart-архивах: **CHECK-COMPUTER.cmd** (Windows) / **CHECK-COMPUTER.command** (Mac) — та же проверка,
ничего не устанавливает; **INSTALL.cmd** / **INSTALL.command** — установка приложения, FFmpeg, Blender,
помощника MediaPipe и демо-дубля.

## Отчёт для поддержки

Кнопка **«Отчёт для поддержки»** сохраняет `MoCapGate-support-<дата>.zip` в «Загрузки». Внутри:
версия и платформа, результат проверки компьютера, состояние компонентов, настройки (без полей с токенами
и ключами; пути могут содержать имя пользователя), краткий список последних 50 дублей (ID, модель, статус,
ошибка, кадры, FPS) и журналы установки. **Видео, анимаций и моделей в отчёте нет.** Приложение никуда его
не отправляет — вы сами решаете, кому его передать.

## Журналы

- установки из приложения: папка `logs` рядом с настройками (macOS — `~/Library/Application Support/MoCapGate/logs`,
  Windows — `%APPDATA%\MoCapGate\logs`, Linux — `~/.config/mocapgate/logs`), хранятся последние 20;
- quickstart: Windows — `%LOCALAPPDATA%\MoCapGate Studio\logs\install-<дата>.log`, Mac — `~/Library/Logs/MoCapGate/`;
- десктопное окно: macOS — `~/Library/Logs/dev.mocapgate.studio/studio.log`, Windows — `%LOCALAPPDATA%\dev.mocapgate.studio\logs\studio.log`.

## Проверка обновлений

Не чаще раза в 6 часов Studio запрашивает список выпусков `api.github.com/repos/MaverickGH/app-releases`
и показывает «Новая версия … — скачать». Данные о вас и дублях не передаются, но GitHub видит ваш IP-адрес.
Автообновления нет. Отключение: «Настройки» → «Проверять новые версии (анонимный запрос к GitHub)».
