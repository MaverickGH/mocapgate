# MetaHuman: текущая интеграция

Цель — просмотр лица в MoCapGate и передача анимации в Maya. На этой стадии
готовы чтение/проверка DNA и экспериментальный экспорт лицевых GUI-кривых.
Просмотр человеческой головы в Studio пока не подключён. Для него требуется
полный DCC-пакет персонажа: геометрия, skin weights, лицевые деформации и DNA.
Сам Faceboard — панель контроллеров, а не геометрия головы.

## Что скачано и проверено на Windows

- Epic [OpenRigLogic](https://github.com/EpicGames/OpenRigLogic), ветка `5.8`,
  коммит `55756aca0c4c55adc56ad68a796bcc1c0bf6fa5a`, лицензия MIT.
- [OpenRigLogic Sample Content](https://www.fab.com/listings/27a81942-69bf-498e-a41f-004d0d2db37b)
  добавлен в библиотеку Fab. Дополнительный ZIP содержит `Sample.dna` и
  `faceboard.json` (MH.6); исходные файлы сохранены локально в `dist/metahuman`.
- Библиотеки DNA/RigLogic собраны для CPython 3.12 Windows x64, MSVC 2022,
  CMake 4.4.4 и SWIG 4.3.1. SWIG 4.5.0 не собрал Python-привязку RigLogic.
- В техническом `Sample.dna` **0 мешей, 2 сустава, 2 raw controls**. Это не
  полноценный человек. Реальная оценка тестового рига дала ожидаемые четыре
  blendshape-значения `[0.7, 0.7, 0.4, 0.4]` с погрешностью менее `0.00001`.
- Все 28 каналов начального профиля найдены в официальном Faceboard. Это
  проверка имён/диапазонов, а не точности мимики конкретного персонажа.

Полные Unreal-файлы этого ресурса Fab выдаёт через Epic Games Launcher либо
плагин Fab в Unreal Engine. Для собственных персонажей Epic описывает
[Export → DCC Export](https://github.com/EpicGames/OpenRigLogic#metahuman-ecosystem-compatibility).
В поставке MoCapGate персонажи Fab не включены: пользователь предоставляет
свой пакет. Условия Fab для ресурсов отличаются от MIT-лицензии OpenRigLogic.

## Выбран обычный человек (8 октября 2026)

По запросу пользователя для основного просмотра нужен обычный человек.
Скачан бесплатный [Metahuman Male Base от Grant Sutrisno](https://www.fab.com/listings/7fa06610-4e1a-46b0-acff-ce218b955d25).
Локальная копия: `dist/metahuman/human/mhc_base_male.mhpkg`, 177880736 байт.
Проверка CRC всех файлов ZIP прошла; SHA-256 и сведения о пакете записаны
в локальный `dist/metahuman/human/verification.json`. Модель не включена в Git
или установочные пакеты.

Это **редактируемый Character для UE 5.8**, а не готовый DCC-риг. В архиве
только `.uasset`, текстуры и служебные JSON; отдельных `.dna` нет. Нужно
импортировать пакет в UE 5.8 с MetaHuman Creator, подготовить лицевой риг
и выполнить штатный DCC Export. Затем проверить полный `head.dna` утилитой
ниже и собрать персонажа в Maya средствами Epic. Unreal Engine и Maya
при этой проверке на данном ПК не обнаружены. Мимика и просмотр этого
персонажа в MoCapGate **пока не проверены и не подключены**.

Также скачан официальный Maya Groom Starter Kit (архив
`maya_groom_template.zip`): он содержит `.mb`, волосы Alembic и текстуры,
но не отдельный DNA. Это образец для волос, а не замена полноценного
лицевого рига. Четыре теста текущего экспортера лицевых кривых прошли;
они не подтверждают деформацию этого персонажа.

## Команда проверки DNA

После установки подходящих для ОС и Python привязок OpenRigLogic:

```powershell
python tools/metahuman_inspect.py head.dna --runtime PATH_TO_BINDINGS --require-geometry
```

Для текущей локальной Windows-сборки `PATH_TO_BINDINGS` —
`dist/metahuman/runtime/lib`. `--require-geometry` завершает проверку с кодом 2,
если в DNA нет геометрии. Новые диагностические утилиты не меняют настройки
установленного Studio.

## Экспериментальная передача мимики в Maya

В дубле должен быть включён захват лица. Используется `person_N.capture_file.json`
с `fps`, идентификатором человека и `frames[].face.blendshapes`.

```powershell
python tools/metahuman_face.py person_1.capture_file.json --faceboard faceboard.json --output person_1.metahuman.json
```

Начальный профиль передаёт челюсть, брови, веки, щёки и основные движения губ
в 28 GUI-каналов. Это приближённое семантическое соответствие; перед рабочим
использованием необходимо проверить направления, амплитуды и сочетания на
настоящем риге. Экспорт перечисляет неиспользованные коэффициенты. Повороты
головы, взгляд, язык и полная мимика MetaHuman ещё не перенесены.
Для собственной калибровки доступен `--mapping profile.json`: объект
`{"CTRL_C_jaw.translateY": {"jawOpen": 0.8}}`, где числа — веса коэффициентов.
Целевые каналы обязательно сверяются с выбранным Faceboard.

В Maya сначала собрать полноценный MetaHuman штатными средствами Epic,
затем выполнить файл `tools/maya/import_metahuman_face.py` в Python Script Editor
и вызвать `import_face('/absolute/path/person_1.metahuman.json', namespace='Ada')`.
Скрипт проверяет наличие и доступность контроллеров до установки ключей,
сохраняет длительность записи независимо от FPS сцены и объединяет импорт
в одну отменяемую операцию. На кадрах без лица ставит нейтральные ключи.
В выбранном диапазоне импорт устанавливает ключи на перечисленных каналах.

Проверены экспорт, защита от неверного Faceboard, отсутствия лица и NaN;
работа внутри Maya и деформация полноценного персонажа пока не проверены.
Эти инструменты есть начиная с 0.3.3 beta (предварительный выпуск для Windows); в стабильной 0.3.2
их нет. Windows-пакет 0.3.3-beta.4
включает утилиты и привязки OpenRigLogic в `tools/metahuman/runtime`;
персонажи и Faceboard предоставляются отдельно. См. [установку Windows](windows-0.3.3-beta.4.md).
